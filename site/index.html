First-launch instructions

This beta is unsigned on Windows and ad-hoc signed on Mac. Verify the SHA-256 file from the release page. On Mac, move Pawprint to Applications; if macOS cannot verify the developer, choose Done and use System Settings → Privacy & Security → Open Anyway. If it says damaged, stop and report the build.

A few things to know

Does it use extra AI tokens?

The pet, work shortcuts, reminders, bookmarks and games run locally without making extra model requests. Your normal Codex usage follows your own plan.

What works on each platform?

Pawprint supports Windows 10/11 x64 and Apple silicon Macs. Chat return needs a compatible Codex desktop client. Native approval hook setup is currently macOS-only; local usage and supported question records also work on Windows.

Is there any setup for reminders?

New installs enable quiet local reminders and prepare Pawprint’s hooks when Codex data is found. Review and trust the labeled Pawprint rows in your client for approval alerts. You choose whether to add sounds or system notifications.

What stays on my computer?

Pets, bookmarks, rooms and usage data stay in your local profile. Pricing and update checks use their existing online catalogs. Nearby visits are optional and use your local network.
