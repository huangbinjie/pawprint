About this GPT desktop pet

How does Pawprint work with ChatGPT and Codex?

Pawprint is an independent desktop companion, not an official OpenAI app. It reads local Codex activity records and GPT-model usage. It does not read your browser's ChatGPT conversations or require an OpenAI API key.

Does Pawprint support Windows?

Yes. Download Pawprint free from GitHub Releases for Windows 10/11 x64 or Apple silicon Mac. Windows shows quota in the system tray menu.
