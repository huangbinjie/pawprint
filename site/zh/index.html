你可能想知道

会额外消耗 AI token 吗？

宠物、工作入口、提醒、书签和小游戏都在本地运行，不额外发起模型请求。正常使用 Codex 的用量仍按你的套餐规则执行。

各平台支持什么？

支持 Windows 10/11 x64 和 Apple 芯片 Mac。返回会话需要兼容的 Codex 桌面客户端；审批 Hook 的设置目前仅支持 macOS，本地用量及受支持的提问记录也可在 Windows 使用。

提醒需要设置吗？

新安装默认启用安静的本地提醒，并在发现 Codex 数据时准备 Pawprint 的 Hook。审批提醒还需要在客户端审核并信任带 Pawprint 名称的规则。是否添加声音或系统通知，由你选择。

哪些数据留在本机？

宠物、书签、房间和用量保存在本地存档。价格目录和更新检查会联网获取现有目录；附近串门是可选功能，使用你的局域网。
