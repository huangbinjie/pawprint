关于 GPT 桌面宠物

爪印和 ChatGPT / Codex 有什么关系？

爪印是独立开发的桌面伙伴，与 OpenAI 无官方关联。它读取本机 Codex 活动记录和 GPT 模型用量；不会读取浏览器中的 ChatGPT 聊天，也不需要 OpenAI API key。

支持 Windows 吗？

支持 Windows 10/11 x64 和 Apple 芯片 Mac。两种安装包均可从 GitHub Releases 免费下载；Windows 使用托盘菜单查看额度。
