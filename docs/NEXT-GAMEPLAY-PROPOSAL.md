# 爪印下一版玩法与经济方案（讨论稿，未实施）

进度更新：v0.5 已实施经济规则与后花园，保留原有余额和宠物。v0.6 已加入才艺、课程与局域网串门/繁育；游历与任务反馈仍是设计建议。全部价格均指宠物币，真钱付费另行设计。

## 已核实的现状

2026-09-20：正式存档有 1 只名为「布丁」的初遇宠物、240 币、3 个饲养位；收入记录为 117、3、120 币，没有付费领养或繁育支出。记录不包含点击者身份。此前开发中的领养与繁育测试使用隔离存档。

当前每日上限 120 币，探索蛋 25 币，系统繁育 45/55 币，扩建 80 币。满额收入在不考虑容量时可买 4 枚蛋并余 20 币。这是功能原型数值，未完成长期经济平衡。单机固定价格下，核心风险是币越来越没有用途、收集目标过快耗尽；联网后还会增加市场价格、资产复制和供给问题。

## 经济 v2 的建议起点

保留现有余额，调整只针对未来的消费，不追溯扣币。

| 项目                     | 建议规则                                               | 用途与边界                                               |
| ------------------------ | ------------------------------------------------------ | -------------------------------------------------------- |
| 第一只宠物               | 免费、立即孵化                                         | 先建立陪伴，不让新用户长时间等蛋                         |
| 后续探索蛋               | 240 币                                                 | 相比现在更有选择成本，抽取规则保持透明                   |
| 系统繁育                 | 180 币起                                               | 系统费用全部退出流通；先测试基础价格，不按官方颜值分定价 |
| 繁育资格                 | 陪伴 3 个活跃日后成年；单只冷却 48 小时，每周最多 2 次 | 活跃日无需大额刷 token，避免无限复制优质组合             |
| 扩建                     | 首次 600 币，后续逐步增加                              | 一次性消费，不能拿它证明长期货币平衡                     |
| 才艺课程                 | 120 币 / 次作为测试起点                                | 提升熟练度、解锁预定动作变化；日常表演免费、不重新抽天赋 |
| 短途游历                 | 80 币 / 次作为测试起点                                 | 带回小故事、照片或纪念品；不按投入返币，不产出可折现物   |
| 后花园安置               | 免费、不返币                                           | 保留宠物与回忆，腾出小屋位置                             |
| 日常陪伴、任务提醒、串门 | 免费                                                   | 作为核心使用价值                                         |

先保持现有每日发币上限 120，观察实际消费，再调整未来发行。不要通过提高官方模型成本、诱导空耗 token 或清空存款来制造难度。

### 获得第二只需要多久

以下是假设收入，不是已观察到的用户平均值。没有把原有余额计入。

| 每活跃日收入 | 240 币探索蛋 | 180 币基础繁育 |
| -----------: | -----------: | -------------: |
|        40 币 |         6 日 |           5 日 |
|        80 币 |         3 日 |           3 日 |
|       120 币 |         2 日 |           2 日 |

还需满足成年与繁育冷却。首次免费蛋立即孵化，后续孵化可以短等待，不把主要难度放在枯燥计时上。

### 钱是否真的回收

系统领养费、系统繁育费、课程与游历报名费是回收。玩家互相支付只是转移；将来玩家配种收费必须把「主人所得」和「系统收取并退出流通的部分」分开。

示例：假设每天 80 币，30 天发行 2400 币。买 2 枚探索蛋 480、繁育 4 次 720、课程 4 次 480、游历 2 次 160，总消耗 1840，仍净增加 560。再扩建一次 600 后，本月净减少 40，但扩建不是每月都会发生，不能据此宣称平衡。

是否会实际购买这些内容尚未验证。要看每活跃用户的发行/消费、存款分布、第二只宠物等待时间和重复玩法参与率。增加商品不等于增加真实消费。玩家选择储蓄时，不强制扣款；不能承诺永远不通胀。

## 不想继续养：去后花园生活

推荐主入口叫「去后花园生活」，不是回收、分解或卖掉。

- 宠物保留名字、基因、才艺、血统和回忆，可随时查看。
- 不占小屋饲养位，休养时不参与训练、繁育或桌面陪伴。
- 小屋有空位即可接回，原有冷却继续计时，不通过往返重置。
- 不返币，不生成可以卖掉换币的奖励，避免批量生育后刷返还。
- 确认界面展示宠物和去向，操作可逆。第一版无需做永久送养或删除。

以后若需要「送养新家」，应单独设计去向、撤销窗口和访问信息，不混成一个卖宠物按钮。

## 出生随机才艺，后天练习

外貌基因仍保持出生前锁定、出生后不改变。才艺是独立系统，不把不好看的宠物判为没有价值。

建议出生时确定 1 个招牌才艺和后续动作变化序列，立即可展示基础版本，练习提高熟练度。反复打开蛋、重启、安置接回都不能重新抽取。

第一版才艺池可以先做：

| 分组     | 建议组概率 | 候选才艺举例       |
| -------- | ---------: | ------------------ |
| 日常动作 |        70% | 挥爪、伸懒腰、打滚 |
| 表演动作 |        25% | 扭扭舞、转圈、敬礼 |
| 招牌表演 |         5% | 月球步、花式翻跟头 |

这是组概率，具体动作概率需在确定动作清单后公开。不同组不是货币收益倍率。

初遇/探索蛋从全局池抽取。繁育蛋可以测试「70% 从父母才艺中选择，30% 从全局才艺池抽取」。才艺规则独立于外貌基因，因此不会违背当前无外貌基因突变的约定。

不让才艺自动印币，也不每跳一次舞收费。课程应解锁可见的表演变化，不出售无限重抽。普通或古怪的外貌配上意外才艺，本身就是收藏与分享的理由。

## 局域网串门

同一局域网的第一版可以不使用自有服务器。建议采用系统支持的 mDNS/Bonjour 发现与本地连接；应用依赖库随爪印打包，无需用户额外安装工具。部分办公/访客 Wi-Fi 会隔离设备，发现能力需要在真实网络中验证。

访问流程：双方打开局域网功能 → 发现附近小屋 → 邀请 → 对方接受 → 宠物临时分身来访 → 手动离开或超时返回。

第一版限定为：最多两只访客、一起玩和展示才艺。所有权不转移，不合并钱包，不做局域网交易或跨设备繁育。避免复制文件就能复制联网资产，金融式账本以后单独设计。

只分享宠物外貌、名字和才艺；不分享 AI 会话主题、正文、用量或目录信息。基础串门免费。以后可测试可选的小礼物或共同活动作为货币消耗，但应有真实体验价值。

## AI 工作状态与宠物反馈

先接已支持的本机 Codex。官方 App Server 定义 turn/started、turn/completed、thread/status/changed 等事件；本地记录也存在 task_started/task_complete。单独启动一个 App Server 不代表自动订阅现有桌面任务，接入现有客户端需要实际验证。

产品表现：

| 状态         | 气泡/动作建议                                    |
| ------------ | ------------------------------------------------ |
| 开始一轮任务 | 短暂显示「在处理：发布说明」，随后收起           |
| 工作中       | 安静的小动作；悬停时可查看状态                   |
| 回复完成     | 「回复好了，点我查看」+ 一次招牌才艺，几秒后消失 |
| 需要用户操作 | 等待姿态与明确提示，优先级高于普通完成           |
| 错误/取消    | 使用不同提示，不播放成功庆祝                     |
| 状态无法确认 | 保持中性，不以没有新增 token 推断完成            |

状态只表示这一轮回复/任务状态，不等于代码已通过测试、部署成功或整个项目完成。多任务只展示一个重点状态，优先级建议需要操作 > 错误 > 最近完成 > 进行中；同一 turnId 只反馈一次，启动不重放旧事件，避免刷屏。

主题显示单独提供开关，优先使用已有任务标题，不额外调用模型总结正文。未授权或取不到标题时显示通用「正在处理任务」。气泡和才艺都短暂出现，保留用户要求的纯宠物桌面风格。局域网访客不获取这些主题。

参考：https://developers.openai.com/codex/app-server

## 实施建议

先完成经济配置化与后花园，再加入出生随机才艺和本机任务反馈。局域网串门单独做双机验证，避免把财产转移和网络同步一起塞入第一版。

验收至少覆盖：旧币与旧宠物保留、首宠不再领取、领取/繁育扣款原子性、冷却跨重启不重置、后花园接回不重抽才艺、同一完成事件只播放一次、多任务与错误状态不误报、双方接受才允许访客出现，以及对方离线后的可靠返回。
