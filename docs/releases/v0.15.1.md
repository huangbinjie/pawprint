# Pawprint v0.15.1 — 更低占用，更清晰的连接 / Lower CPU, clearer connections

## 中文

- **降低动画 CPU 占用**：呼吸、眨眼、尾巴和耳朵动画共享 30 Hz 更新时钟，跳过静止片段，并在隐藏或离屏时暂停更新。
- **默认保留 Dot 等账号入口**（macOS）：第三方连接保留内置 OpenAI 身份，模型请求仍经本机代理发往选中的服务，并使用该服务的 API Key。移除兼容模式开关，也不再按 `tbo_available` 自动切换策略。
- **修复新会话的 `Invalid JSON request` 错误**：支持原生客户端发送的 Zstd 压缩请求，并处理 gzip、deflate、Brotli；压缩前后均有限定大小。改善 WebSocket 到 HTTP 的回退，登录凭据不会转发给第三方。
- **更快显示 Provider 标题前缀**：请求发出时即记录目标服务，正式标题生成后及时添加前缀，不再等待整段回复结束。最初根据首条消息显示的临时标题仍保持客户端原有行为。
- **菜单栏立即跟随连接切换**（macOS）：选用第三方时显示 Provider 名称，例如 `My API`，不带 `W`；切回 ChatGPT / OpenAI 后恢复额度显示。失败的切换保留原显示，第三方空额度记录不再覆盖已知的官方快照。
- 保留原有登录、宠物、钱包和偏好；升级时清理旧的模式设置，不重置已兼容连接中由客户端选择的模型。

### 使用说明

- 保留账号入口需要已识别的文件型 ChatGPT 登录；Dot 等功能是否可用仍取决于账号与客户端权限。使用第三方服务时请保持 Pawprint 运行。
- 菜单栏官方额度来自本机记录，并非实时服务器查询；第三方余额和额度尚未接入，以服务商后台为准。
- 默认连接切换不会迁移正在运行的会话。使用内置 OpenAI 身份创建的会话在重新加载后可能跟随新的默认服务，历史上下文也可能随下一次请求发送给该服务。
- Provider 管理仅支持 macOS。Windows 也包含动画优化；Windows 桌面交互仍需实际设备验证。

## English

- **Lower animation CPU usage:** breathing, blinking, tail and ear motions share a 30 Hz clock, skip unchanged segments and pause when hidden or offscreen.
- **Preserve Dot and account entries by default on macOS:** third-party connections retain the built-in OpenAI identity while inference is routed through the local bridge using the selected provider's API key. The compatibility switch and `tbo_available`-based policy selection are removed.
- **Fix `Invalid JSON request` in new chats:** decode native Zstd requests, as well as gzip, deflate and Brotli, with size limits on both encoded and decoded bodies. Improve WebSocket-to-HTTP fallback without forwarding ChatGPT credentials to providers.
- **Earlier provider title prefixes:** observe the destination when dispatching a request and label the generated title without waiting for the full reply. The client's initial temporary title remains unchanged.
- **Immediate menu-bar connection feedback on macOS:** third-party selections show the provider name, such as `My API`, without `W`; ChatGPT / OpenAI selections restore the quota display. Failed switches retain the previous label, and empty third-party quota records no longer overwrite known official snapshots.
- Preserve login, pets, wallet and preferences. Remove obsolete mode preferences without resetting a client-selected model on an already compatible connection.

### Usage notes

- Preserving account entries requires a recognized file-based ChatGPT login. Feature availability still depends on account and client permissions. Keep Pawprint running when using the local bridge.
- Official quota is a local snapshot, not a live account query. Third-party balances and quotas are not queried; use the provider's dashboard.
- Switching defaults does not migrate active chats. Chats created with the shared OpenAI identity may follow a new default service after reloading, including sending existing context with the next request.
- Provider management is macOS-only. Windows also receives the animation optimization; interactive Windows desktop behavior still needs hands-on verification.
