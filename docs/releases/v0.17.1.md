# Pawprint v0.17.1 — 更新回退 / Updater fallback

## 中文

- 修复 GitHub API 匿名额度耗尽时应用内更新失败的问题。
- GitHub API 返回 403 时，更新器改用公开的 `releases/latest` 页面和发布资产直链；下载仍会校验 SHA-256、大小和应用标识。

## English

- Fix in-app updates when GitHub's anonymous API quota returns 403.
- When the GitHub API is rate-limited, the updater falls back to the public `releases/latest` page and direct release assets. Downloads still verify SHA-256, size and the application identity.
