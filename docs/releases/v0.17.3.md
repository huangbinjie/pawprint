# Pawprint v0.17.3 — 启动后恢复重试 / Startup retry recovery

## 中文

- 修复 Pawprint 在 Codex 会话已经开始后才启动或重启时，漏掉 high-demand 失败的问题。
- 启动时恢复最近 30 分钟的会话生命周期；最近的 high-demand 失败会继续进入自动重试，仍遵守每轮 5 次、最多 3 轮的上限。
- 普通内部错误、额度保护、权限和参数错误继续不会自动重试。

## English

- Fix missed high-demand failures when Pawprint starts or restarts after a Codex turn has already begun.
- Recover recent session lifecycle records from the last 30 minutes at startup; recent high-demand failures continue into automatic retry with the existing five-per-round and three-round limits.
- Generic internal errors, quota protection, permission errors and parameter errors remain excluded from automatic retry.
