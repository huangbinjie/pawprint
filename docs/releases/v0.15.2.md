# Pawprint v0.15.2 — MiMo 模型适配与用量修复 / MiMo routing and usage fixes

## 中文

- **按连接模型选择转发方式**（macOS）：配置的模型 ID 在 Codex 原生模型列表中时，继续使用聊天框选择的模型；不在列表中（例如 MiMo）时，聊天、标题生成和上下文压缩使用连接中配置的模型。读取列表失败时保留聊天框选择并提示重试，可通过“刷新状态”重新检测，无需新增模式开关或替换客户端模型目录。
- **修复第三方工具调用所需的协议头转发**：保留功能标记和其他端到端 HTTP 头，包括 `x-openai-internal-codex-responses-lite`；过滤登录凭据、账号身份和逐跳头，使用所选服务的 API Key。压缩响应保留原始字节与对应编码，流式回复继续实时传输。
- **按实际模型展示 MiMo 用量**：将成功转发请求的会话、轮次和实际模型与 Codex 原生 Token 记录对应，避免把新产生的 MiMo 用量显示为 GPT。没有准确轮次证据的历史记录保持原标注，冲突记录不猜测归属。
- **补充 MiMo 模型参考费用**：优先使用小米官方 API 模型价格表作为参考，不把订阅套餐的零单价当成免费 API。参考费用不等于套餐扣费、余额或剩余额度，不额外增加宠物币。

### 使用说明与已知问题

- 第三方服务需支持 Codex 所需的 Responses API 和工具行为；使用本机连接代理时请保持 Pawprint 运行。默认连接切换不会迁移正在运行的会话，切回 ChatGPT / OpenAI 后恢复原生模型选择。
- 本轮 macOS 实测已确认 MiMo 可调用工具并展示新增用量；Windows 继续由 CI 构建并执行基本运行及更新检查，Provider 管理仍仅支持 macOS。
- 已收到 macOS 菜单栏入口不显示的反馈，原因仍在调查；本次不包含该问题的修复。

## English

- **Choose routing from the connection's configured model on macOS:** keep the Codex model picker when the configured ID appears in the native model list. Otherwise, use the configured model for chat, title generation and compaction, including MiMo connections. If the list cannot be read, preserve picker selection and show a retry notice. Refresh Status retries detection without adding a mode switch or replacing the client catalog.
- **Forward protocol headers needed by third-party tool calls:** preserve feature flags and other end-to-end HTTP headers, including `x-openai-internal-codex-responses-lite`. Strip credentials, account identity and hop-by-hop headers, and authenticate with the selected service's API key. Preserve compressed response bytes with matching encoding headers and forward streaming replies as they arrive.
- **Attribute new MiMo usage to the forwarded model:** match successful requests to Codex's native metering records by thread and turn. Historical records without exact routing evidence retain their original labels; conflicting routes remain unattributed.
- **Show MiMo reference costs:** prefer Xiaomi's API model prices instead of treating a subscription plan's zero per-token rates as a free API. Reference costs are separate from subscription charges, balances and remaining quota, and do not mint extra pet coins.

### Usage notes and known issues

- Third-party services must implement the Responses API and tool behavior required by Codex. Keep Pawprint running while using the local bridge. Changing the default connection does not migrate running chats; returning to ChatGPT / OpenAI restores native model selection.
- MiMo tool calls and new usage display were manually verified on macOS. Windows builds, basic runtime checks and updater checks run in CI; Provider management remains macOS-only.
- A missing macOS menu-bar entry has been reported and remains under investigation. This release does not include a fix for it.
