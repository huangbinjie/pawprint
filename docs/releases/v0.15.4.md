# Pawprint v0.15.4 — 会话服务绑定与连接修复 / Persistent chat services and connection fixes

## 中文

- **会话固定绑定服务**（macOS）：切换默认 Provider 只影响新会话；已有会话重载、Codex 重启或 Pawprint 重启后仍使用绑定服务。GPT 或支持选模的网关仍可在聊天框切换模型；MiMo 等固定模型连接继续使用配置模型。删除原 Provider 后，旧会话会明确报错，不会改走其他服务。
- **更清楚地显示默认连接与会话来源**：连接页改为“新会话默认服务”，最近会话来源中显示绑定服务。实际请求回到官方 GPT 时，只移除 Pawprint 自己添加的 Provider 标题前缀，保留手动编辑的标题。
- **修复删除 Provider 看似无反应**：确认区域改为居中弹窗，默认聚焦取消按钮；显示删除进度和失败原因，支持取消、Esc 关闭及失败后重试。
- **修复旧 GPT 会话转发时的 502**：官方请求适配 Electron 网络层，让网络层自行生成请求长度与浏览器控制头；保留登录和应用协议头，并正确处理压缩响应与流式内容。
- **附带 macOS Tahoe 菜单栏定点修复工具**：部分开发环境中，系统会把 Pawprint 的菜单项关联到启动它的 IDE／助手名下，使 Pawprint 随另一个应用的菜单栏开关一起隐藏。附带的 `Pawprint-macos-menubar-association.py` 可预览关联，手动应用时先备份，只解除其他应用名下的 Pawprint 关联，保留其他开关与布局，失败时尝试恢复备份。需要已有完整磁盘访问权限的终端；工具不会重启 Pawprint 或 Codex，也不会自动开启任何权限。

### 升级与使用说明

- **请保持 Pawprint 运行**：为保证会话绑定，升级后的官方 GPT 与第三方请求都经过本机路由。服务绑定管理仅支持 macOS；远端会话不由此路由接管。
- **已有会话迁移**：优先保留已确定的服务绑定及显式 Provider；原生 OpenAI 标识的会话有转发记录时按记录绑定，没有记录时绑定官方 GPT。绑定文件缺失或损坏时停止转发，避免误用当前默认服务。
- **菜单栏修复为可选手动操作**：先下载工具及其 SHA-256 文件核对。`python3 Pawprint-macos-menubar-association.py` 仅预览；需要修复时再运行 `python3 Pawprint-macos-menubar-association.py --apply`。备份和结果保存在 `~/Library/Application Support/Pawprint/menubar-repair-backups/`；应用修复会刷新 ControlCenter 和当前用户的偏好设置缓存进程。本机已确认 ChatGPT 菜单栏关闭时 Pawprint 可独立显示；这不是对所有菜单栏故障的通用修复。
- 本地验证覆盖 Node 单元测试、Provider 与语言界面回归、修复工具的备份／回滚／进程保护，以及真实 Codex 后端跨重启路由。官方完整转发回归使用临时配置与本机模拟服务；未自动发送真实聊天请求。Windows 安装、基本运行与更新继续由 CI 检查。

## English

- **Persist each chat's service on macOS:** changing the default Provider affects new chats. Existing chats keep their service after reloads and Codex/Pawprint restarts. GPT and picker-capable gateways retain model selection; fixed-model connections such as MiMo use their configured model. Deleting a bound Provider produces an explicit error rather than falling through to another service.
- **Clarify defaults and chat sources:** label the selected connection as the default for new chats and show each recent chat's bound service. After an observed official request, remove only a Provider title prefix owned by Pawprint; preserve manually edited titles.
- **Make Provider deletion visible:** open a centered confirmation dialog with cancellation focused by default. Show progress and errors in the dialog, with cancellation, Escape and retry support.
- **Fix 502 errors when forwarding older GPT chats:** let Electron generate its own request framing and Fetch Metadata. Preserve authentication and application protocol headers while handling decoded compressed responses and streaming consistently.
- **Include an optional macOS Tahoe menu-bar repair tool:** a status item can be associated with the IDE/assistant that launched it, so disabling that application's menu-bar entry also hides Pawprint. The attached `Pawprint-macos-menubar-association.py` previews these associations. Applying a repair backs up first, removes only foreign Pawprint associations, preserves other permissions/layout and attempts rollback on failure. It requires a terminal with Full Disk Access, never grants permissions automatically and does not restart Pawprint or Codex.

### Upgrade and usage notes

- **Keep Pawprint running:** both official and third-party inference use the local router after upgrade so chat bindings remain effective. Service binding management is macOS-only; remote chats are not taken over by this router.
- **Existing-chat migration:** retain established bindings and explicit Providers. For native OpenAI-labelled chats, use observed routing evidence when available and official GPT otherwise. Missing or corrupt binding metadata stops forwarding instead of guessing from the current default.
- **Menu-bar repair is manual and optional:** verify the tool against its SHA-256 file. Run `python3 Pawprint-macos-menubar-association.py` to preview, and add `--apply` to repair. Backups/results go to `~/Library/Application Support/Pawprint/menubar-repair-backups/`. Applying refreshes ControlCenter and the current user's preferences-cache daemon. Independent visibility with the ChatGPT menu-bar toggle disabled was verified on the affected local machine; this does not claim to fix every menu-bar problem.
- Local validation covers Node tests, Provider/language UI regression, repair backup/rollback/process protection, and native Codex backend restarts. Complete official-transport regression uses temporary profiles and loopback mock services; no real chat is sent automatically. Windows packaging, runtime smoke and updater checks run in CI.
