# Pawprint v0.16.0 — 更顺手的 Codex 助手 / Make Codex Assistant your own

## 中文

- **预制动态皮肤（macOS）**：在「Codex 助手 → 皮肤」选择夜窗陪伴、暖阳猫窝或阳光狗屋，直接查看预览与当前主题。视频首次从 GitHub 异步下载，显示进度并校验大小与 SHA-256，缓存后离线可用；无需安装 QQ 音乐。夜窗带新会话开场动画，猫咪使用坐姿待机循环，旧版过渡动画缓存会自动升级。可随时恢复默认外观。
- **本机会话管理**：独立入口搜索最近最多 5,000 条本机会话，支持模糊匹配、返回会话、批量归档／取消归档，以及确认后永久删除；每次最多处理 200 条。永久删除同时移除对应的本地会话记录文件。
- **模型过载自动重试**：每轮立即重试最多 5 次，仍然过载则等待 30 秒进入下一轮，最多 3 轮（15 次自动重试，不含最初失败）。用户主动点重试会取消旧等待并重新计数；成功或停止后结束重试。界面与猫咪气泡显示轮次、本轮次数和轮间倒计时。
- **原生能力路由修复（macOS）**：聊天 Responses 与压缩请求继续使用会话绑定的服务，图片生成等其他原生能力使用保存的官方账号连接，避免发给第三方聊天 Provider。实际可用性仍由账号、客户端与官方服务决定。
- **中英文与运行时更新**：补齐会话管理、皮肤、下载失败和连接提示的英文；中英文官网、README 与本说明同步更新。Electron 更新至 44.10.0，包含受损中间证书缓解等修复。

### 使用与验证

- 保持 Pawprint 运行，才能在客户端重开后恢复皮肤并处理新发生的过载。重试沿用当前会话的模型与权限，不重放工具命令，不补重试启动前的历史失败。
- 皮肤和 Provider 管理目前仅支持 macOS。会话功能依赖兼容的本地 Codex 数据库及桌面 IPC；客户端更新可能改变内部协议。连接运行中的客户端可能需要确认重开，Pawprint 不会在首次启动时自动中断已有客户端。
- 宠物、基因、余额与已有设置保留。Windows 安装包、基本运行和应用内升级由 Windows CI 检查；Mac 仍为 ad-hoc 签名、未公证的测试版。
- 验证使用隔离的本地记录与模拟服务，不将真实模型可用性、账号权限或手动桌面体验视为自动测试已证明。

## English

- **Preset animated skins on macOS:** choose Night Companion, Sunny Cat Room or Sunny Puppy Room in **Codex Assistant → Skins**, with previews and the current selection. Videos download asynchronously from GitHub with progress, byte-size and SHA-256 verification, then remain cached for offline use. QQ Music is not required. Night Companion includes a new-chat opening; the cat uses a seated idle loop, automatically replacing the old transition clip. Restore the original appearance at any time.
- **Local chat management:** a dedicated section searches up to 5,000 recent local chats, with fuzzy matching, return shortcuts, batch archive/unarchive and confirmed permanent deletion, up to 200 chats per operation. Permanent deletion also removes the corresponding local session record files.
- **Automatic overload retries:** retry immediately up to 5 times per round; if overloads continue, wait 30 seconds before the next round, up to 3 rounds (15 automatic retries, excluding the original failure). Clicking Retry manually cancels the old cooldown and resets both counts. Success or stop ends the retry chain. Chat surfaces and the companion bubble show the round, attempt and between-round countdown.
- **Native capability routing on macOS:** chat Responses and compaction continue using the chat's bound service. Other native capabilities, including image generation, use the saved official account connection instead of a third-party chat Provider. Availability still depends on the account, client and official service.
- **English, Chinese and runtime updates:** complete English labels for chat management, skins, download failures and connection prompts; update both website languages, READMEs and these notes. Electron 44.10.0 includes compromised intermediate-certificate mitigations and other fixes.

### Usage and validation

- Keep Pawprint running to restore skins after client restarts and handle new overloads. Retries inherit the current model and permissions, never replay tool commands and do not replay historical failures on startup.
- Skins and Provider management currently require macOS. Chat helpers depend on a compatible local Codex database and desktop IPC, which can change with client updates. Connecting an already-running client may require a confirmed restart; Pawprint does not automatically interrupt that client on initial startup.
- Preserve pets, genes, balances and existing preferences. Windows CI checks packaging, runtime smoke and in-app upgrades. Mac builds remain ad-hoc signed and unnotarized beta builds.
- Validation uses isolated records and mock services; automated tests do not establish live model availability, account permissions or every interactive desktop behavior.
