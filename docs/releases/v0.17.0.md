# Pawprint v0.17.0 — GPT 额度保护 / GPT quota guard

## 中文

- **聊天额度保护**：Codex 助手 → 高级设置默认开启额度保护，默认阈值为 10%，可调至 5%–80%。有有效的 5 小时额度时自动保护 5 小时窗口，否则保护周额度。
- **代理边界拦截**：达到阈值后，Pawprint 在本机会话代理层拦截绑定 OpenAI/GPT 会话的 Responses 请求，不修改 Codex 客户端按钮，也不影响第三方 Provider 会话。
- **明确错误来源**：主动拦截返回带有 `pawprint_quota_guard` 和 `X-Pawprint-Error` 标记的错误，并按 Pawprint 当前语言返回中英文提示；使用 400 避免被 Codex 当作服务端 429 自动重试。
- **保留切换空间**：已经发出的请求不会中途终止；后续 GPT 请求会被拦截，切换到第三方 Provider 后继续使用。

## English

- **Chat quota guard**: enabled by default in **Codex Assistant → Advanced settings**, with a 10% default threshold and selectable thresholds from 5% to 80%. It automatically guards the 5-hour window when a valid one exists, otherwise the weekly window.
- **Proxy-boundary blocking**: once the threshold is reached, Pawprint blocks Responses requests for chats bound to OpenAI/GPT at the local session proxy. It does not change Codex's UI controls and does not block third-party Provider chats.
- **Clear error ownership**: blocked requests carry the `pawprint_quota_guard` and `X-Pawprint-Error` markers, with Chinese or English text following Pawprint's current language. The response uses 400 so Codex does not treat it as a retryable service 429.
- **Provider switching remains available**: requests already in flight are not interrupted. Subsequent GPT requests are blocked, while a switched third-party Provider can continue.

### 验证 / Validation

- Quota and proxy tests cover automatic window selection, threshold validation, Chinese and English error messages, source markers, no upstream dispatch, and third-party pass-through.
- Full Node test suite and macOS arm64 packaging passed locally. The Mac artifact is ad-hoc signed and not notarized when built without release signing secrets.
