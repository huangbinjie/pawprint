# Pawprint v0.11 · 悬浮修复与中英文切换

## 悬浮窗口修复

以前缩小宠物只改变视觉大小，网页布局仍保留原尺寸，因此鼠标进入时会出现滚动条，滚轮还能把内容移走。现在悬浮窗口采用固定画布，自己的宠物、蛋、访客和双宠物合演都不会形成可滚动页面。小屋的页面滚动保持正常。

已验证 50%、70%、100% 尺寸下的悬停、水平及垂直滚轮、程序滚动，以及 70% 访客合演窗口。

## 切换语言

在「偏好设置 → 界面语言」选择 English 或简体中文，也可点击 macOS 菜单栏的爪印图标，进入「语言 / Language」切换。立即生效，自动保存，重启保留。当前使用习惯保持中文，直到你主动切换。

English: Open Preferences → Interface language → English. You can also use Language in the macOS menu bar menu. Changes apply immediately and persist across restarts.

界面、基因与技能名称、搜索、弹窗、错误提示、原生菜单、通知和会话气泡支持英文。基因图鉴可按英文名称搜索，也兼容中文搜索。系统权限弹窗遵循 macOS 的语言选择。

宠物名字、同事小屋昵称保持原文；语言切换不改基因、技能、币、账本、冷却或网络身份。英文模式下新孵化伙伴的默认名字使用英文，已有伙伴不会自动改名。中英文客户端可以正常连接与串门。

翻译内置于安装包，不调用在线翻译或模型，不额外消耗 token。

## 检查范围

78 项核心测试、13 条桌面流程通过，包含英文九页面、基因搜索、基因档案与改名、错误提示、菜单栏语言、会话开始/结束气泡、重启保持，以及中英文两客户端的配对、串门、合演。实体第二台电脑与不同办公室网络仍需实际环境验收。

当前仍为未签名、公证的 Apple 芯片 Mac 内测包，支持 macOS 13+。
