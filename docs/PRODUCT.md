# 单机版产品边界

## 当前方向

用户授权由爪印直接提取本机 Codex 使用记录，以模型等价费用归一化后获得宠物币。宠物币用于蛋、系统繁育和饲养位。宠物外貌由遗传数据确定，可看到父母特点延续到后代。装饰、联网和盈利实现后置。

暂名：爪印 / Pawprint。当前桌面平台 macOS，参数化 2D 矢量猫咪，包含普通、清瘦、蓬乱与纯色气质；画风与产品名可以后续调整。

## 本轮验收入口

1. 第一次打开小屋，免费领取初遇蛋并孵化，命名宠物。
2. 打开基因档案，查看外貌表现和两个携带基因。
3. 明确授权读取本机 Codex 记录，显示真实用量，领取当天奖励。
4. 重复刷新 / 重启不能重复领取同一份奖励。
5. 选择系统伙伴，预览各性状概率，支付宠物币，生成继承双方基因的蛋。
6. 孵化第二代，在图鉴检查血统；重启仍能看到同一外貌和余额。
7. 把选中的宠物放到桌面悬浮，打开小屋或关闭悬浮。

## 尚未实现

完整 AI 聊天 / 语音 / 任务状态联动；多物种；连续斑点位置与大小基因；突变；长期数值平衡；装饰；联网用户、配种市场、支付、云存档、自动更新、签名公证分发。

## 未来盈利方向

先验证免费首宠与本地完整玩法买断的意愿。联网之后再考虑云同步与管理会员、容量、内容扩展。收取宠物币费用是货币回收，并非营业收入。

本地币和可修改的本地基因不能自动导入未来交易市场。未来需独立的权威账本、用量来源核验、服务器签发和繁育规则。保留本地宠物的陪伴与展示价值。

## 下一轮优先验证

- 美术：是否足够可爱，各基因差异是否一眼能看出。
- 体验：正常工作后是否愿意再打开小屋。
- 动机：是否愿意用攒来的币，追求某一种后代外貌。
- 定价：是否愿意为完整本地玩法付费。

当前奖励与成本参数只是可玩原型的起点，不代表已经验证留存、营收或无通胀。

## v0.3 已交付

极简悬浮宠物，无工具栏和名称条；拖动移动、双击小屋、右键与菜单栏管理。12 类 99 个加权基因，外貌由体型、脸型、毛质、神态等共同决定。基因图鉴展示所有获取选项、初代显现/携带概率、稀有度和来源，配种展示真实条件概率。稀有度按概率而非颜值区分。旧基因保留，新类别补齐中性默认值。

## v0.4 已交付

内置 Codex JSONL 读取器、版本化模型计价、后台扫描和统计缓存；删除外部统计程序依赖。支持自动发现与自选记录目录。切换读取来源先建立基准，保护旧余额并避免重复发币。覆盖本机 Codex 桌面端 / CLI 的本地记录，尚不汇总网页版或其他 AI 产品。

## v0.5 第一阶段已交付

经济 v2：探索蛋 240 币、系统繁育 180/220 币，扩建 600 币起、每次增加 300；3 个陪伴活跃日成年，48 小时冷却，连续 7 天最多 2 次。钱包显示发行与支出。后花园可逆安置、免费、不返币、不占位，暂停成长和繁育，接回不重置基因与冷却。旧余额、宠物与旧蛋均保留。随机才艺、任务反馈与局域网串门后续实施。

## v0.6 已交付

171 个基因/16 类，新蛋采用表现位与携带位以减少低编号特征偏置，旧宠物外貌保持。出生随机才艺、免费表演、两级付费练习。局域网默认关闭，通过加密连接与连接码双向核验配对；邀请确认后访客在桌面出现。双方确认配种，申请方支付 240 币、对方获得 60 币、系统回收 180 币，申请方得到蛋；持久化预留与回执处理重试、取消和断线。任务反馈气泡、游历及云账户仍未实施。
