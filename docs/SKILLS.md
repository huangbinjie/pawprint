# Pawprint v0.10 · 技能图鉴与尺寸

每位伙伴默认掌握玩球，另有 1 项出生才艺、1 项待机技能、1 项社交技能。目录合计 17 项，可形成 128 种出生技能搭配（不含等级和基因差异）。

在「才艺小剧场」的技能池中查看「已拥有」标记与完整概率；技能在蛋生成时锁定，孵化只揭晓。旧宠物、旧蛋按固定 ID 补发待机及社交技能，不改变原才艺等级、基因、余额、血统或冷却，升级和重启不会重抽。

## 获取与遗传

玩球 100% 赠送。其他三个池分别抽一项，每个池的概率单独合计 100%，不能把不同池的概率相加。这里的稀有度按初代抽取频率：≥20% 为基础、≥5% 为少见、低于 5% 为稀有；稀有不表示更赚钱。

繁育时每一类独立按 70% 从父母同类技能中等概率选择、30% 按该池初代权重随机。某技能概率 = 30% × 初代概率 + 父方拥有时的 35% + 母方拥有时的 35%。例如双方都拥有星光合奏，后代得到它的概率为 70.9%。繁育页面显示父母对应的实际概率。

表演和玩球免费，不发币。原来的 120/240 币课程只提升出生才艺等级，不重抽技能；新增待机和社交技能目前没有付费训练或洗技能入口。

## 待机与联机怎么用

开启偏好设置里的待机玩法后，宠物会散步、玩球或展示自己实际拥有的待机技能；技能页也能主动演示。待机技能不会在每次播放时随机换成另一种。

联机时双方升级到 v0.9。访客获得接待方批准并来到桌面后，在「附近的小屋」的访客卡片选择带领者。只要带领者拥有该社交技能，就能带另一只一起演，但不会永久传授技能。合演在接待方桌面显示 8 秒，可以点 × 提前结束；访客离开、断线或 Codex 开始工作也会结束。当前没有在来访者原电脑同步播放动画。

新增协议包含技能资料。已有未决繁育会继续核对旧回执或取消确认，不因为更新就直接退款或再发一枚蛋。

## 调节尺寸

偏好设置 → 桌面陪伴 → 桌面宠物尺寸。50%–100% 可调，滑动即时预览并自动保存，也可用 60%、75%、100% 快捷按钮。宠物、蛋、访客以及透明窗口一起缩放，小屋界面不缩放。边界巡游使用实际缩小后的尺寸，重启后保留。

## 3D 讨论

3D 的主要增量成本在角色建模、拓扑、骨骼绑定、动画、毛发材质和基因驱动形变。现有毛色较容易迁移到材质，但脸型、耳形、体型、尾形及它们的组合需要额外适配；还要控制桌面常驻时的 GPU 使用与耗电。

粗略规划上，现成模型的演示可能几天到两周；支持当前基因与动作的定制成品通常需要数周到数月，具体取决于美术质量、物种数量与团队能力，不能把原型工期当成成品报价。更经济的下一步是先改善 2D 的分层关节动作、头部朝向、表情和光影，评估效果后再决定是否换 3D。
