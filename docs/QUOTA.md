# Pawprint v0.10 · 菜单栏额度与授权说明

## 显示什么

爪印图标旁可以显示 `W 38%`：W 是周额度，数字是剩余百分比。例如 Codex 报告已用 62%，剩余就是 38%。5 小时额度用 `5h` 标记。不要只凭 CodexBar 菜单栏的 W 和百分比判断它显示的是已用还是剩余，需看其设置或展开菜单。

在「偏好设置 → 菜单栏额度」开启或关闭，选择周、5 小时或两者；原生菜单栏菜单也有入口。默认新安装关闭；本次按你的请求开启周剩余显示。

## 数据来源与边界

应用每 15 秒从本机 Codex 会话记录中读取额度快照。按时间窗长度识别周/5 小时，只使用主 Codex 桶，不把 Spark 等其他模型额度混进来。不会由 token 用量估计百分比，也不改变宠物币的计算。

- 不新增账号授权，不读 auth.json、浏览器 Cookie 或钥匙串，不调用在线额度接口。
- `~` 表示超过 15 分钟的旧快照，或读取失败后保留的上次记录。
- `—` 表示没有该窗口的数据，或已经过了重置时间，需要新记录。不会自动猜成满额。
- 菜单与设置页显示记录时间。点击「重新读取」只重新读取本地文件，不向服务器刷新。
- 数据来自本机最近活动的 Codex 记录，无法可靠辨认账号切换，也不能实时反映其他设备后续消耗。停止使用 Codex 后可能没有新快照。
- 仅扫描近期修改的会话，读取有时间、数量、大小上限；格式变化、文件缺失或权限不足时显示未知/错误。

## CodexBar 的授权是什么

已查看当前 CodexBar 的公开源码与文档：

1. OAuth 读取路径会从既有 Codex 登录文件中读取访问令牌，再带着令牌请求额度接口。令牌是登录凭据，不能把这一行为理解为获得了一个「只能看额度百分比」的专用权限；其文档中的 read-only 主要描述不改写共享凭据、不自行刷新令牌。
2. 网页路径可以导入浏览器 Cookie。若系统弹出钥匙串授权，可能涉及已保存凭据或 Cookie 的解密密钥。具体允许哪个项目、采用哪条路径，必须以弹窗文字为准。你提供的图片只有菜单栏，没有授权弹窗，因此不能确定当时是哪一种。

爪印当前使用本地额度快照，不需要上述凭据读取授权。若以后要像在线客户端那样主动实时查询，再单独设计登录、权限说明和退出机制。
