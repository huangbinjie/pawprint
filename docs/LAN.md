# 同事小屋内测指南与协议边界

## 使用

双方安装同一版本爪印。当前提供 macOS 13+、Apple 芯片 Mac 内测包，Windows / Intel 构建尚未验证。

1. 确认在可互通的局域网。当前仅支持 IPv4 局域网。同一 Wi-Fi 不一定互通：访客网络、办公网络设备隔离或防火墙可能阻止访问。
2. 在「附近的小屋」点击开启并阅读说明。macOS 若询问本地网络访问，需要用户按所在公司的策略决定是否允许。
3. 设置小屋昵称，一方复制连接码，自己发给同事。另一方粘贴并申请连接，接收方确认。
4. 选择要派出的伙伴，申请串门。对方点击「欢迎来玩」后，访客出现在其桌面；右键可表演或送回。
5. 双方宠物均满足成年与繁育规则时可以申请配种。先看父母与后代概率，再确认费用；对方也需打开确认面板接受。

连接码包含局域网地址和配对能力，仅分享给信任的同事。应用内依赖均随包提供，不需要安装 Node、Python、Bonjour 工具或云服务器。

## 配种费用与蛋

- 申请方预留 240 币和一个蛋位，亲本暂时不能被再次配种或安置。
- 对方接受后，60 币答谢进入对方钱包，180 币作为系统费用退出流通，蛋归申请方。
- 双方的亲本都会记录一次繁育与冷却。
- 对方拒绝/确认取消后，申请方的预留释放，不扣款。
- 等待超过 5 分钟会尝试取消；断线时保持预留，重连后核对。不能因为暂时联络不上就自动退款，否则可能出现对方已确认并收款的矛盾状态。

## 持久化与重试

申请方以随机请求 ID 写入预留，再发送请求。接收方接受时，在同一次原子保存中写入固定后代、收入和繁育次数。这个回执可重复读取，重复接受不会重新生成。

申请方得到有效回执后，在同一次保存中扣除费用、解除预留、生成一枚蛋和记录繁育次数。重复回执不会重复执行。取消通过接收方持久化的取消记录确认；已经接受的配种以既有回执完成。

配种游戏记录在 save-v1.json。设备证书、连接凭据和配对设备在 lan-private-v1.json（权限 0600，并保留 .bak）。导出游戏存档不包含设备私钥和连接凭据。更新应用应保留 Application Support/Pawprint 整个目录。

重新联网后会自动核对未决请求。自动发现不可用时，重新粘贴同事当前连接码可以更新地址。若一方把身份文件和备份都删除了，正常重连无法证明原身份，需要恢复备份并人工核对，不能保证无条件自动恢复。

## 隐私与限制

- 配对与请求使用 HTTPS，按连接码中的 SHA-256 证书指纹校验，再核实申请设备确实拥有其证书；不是信任任何同名小屋。
- 附近发现只广播小屋信息；宠物资料需要配对令牌。浏览器跨站请求被拒绝，不开放任意文件或命令接口。
- 共享仅包含宠物标识、名字、基因、代数、才艺及繁育可用状态。聊天内容、用量、目录和余额不会发给对方。
- 默认不联网；关闭后停止监听、结束访客。最多 12 个配对设备、2 位访客，来访最长 10 分钟。
- 本地存档可修改，无法防止恶意同事伪造其资产、回滚存档或多开设备。本版本不用于真钱或可信市场。
- 公开分发还需要开发者签名与公证；当前包为未公证内测版。不要为此关闭系统安全保护，按公司软件批准流程使用。

## 验证范围

自动化测试在本机用两个独立 Electron 客户端和独立存档，通过真实 HTTPS 回环连接验证配对、邀请确认、访客悬浮、配种、费用分配、重启及重复请求。另有协议测试覆盖取消与接受竞态、断线保留、伪造回执和设备身份核验。

尚未在第二台实体同事电脑和实际办公 Wi-Fi 完成验收；自动发现、系统权限及网络隔离属于需要实际环境确认的部分。

## v0.9 社交技能

双方请升级到 v0.9；新协议包含技能版本。来访获得接待方同意后，在接待方「附近的小屋」的访客卡片上选择由哪一位伙伴带领，使用带领者实际拥有的社交技能。两位伙伴在接待方桌面同台表演 8 秒，原本悬浮的自家伙伴暂时隐藏，演出后恢复。点击 × 可提前结束；送回访客、关闭局域网或掉线同样会结束。当前不会在来访者原来的电脑重复播放动画。

技能只是合作动画，不转移宠物、技能或钱，不改繁育冷却。已有未决繁育仍按原回执结算，不因更新直接退费或重新发蛋。
