# 爪印 · Pawprint

[产品主页](https://huangbinjie.github.io/pawprint/) · [下载最新 Mac 版](https://github.com/huangbinjie/pawprint/releases/latest) · [全部版本](https://github.com/huangbinjie/pawprint/releases)

随你的工作一起长大的本地基因宠物。当前是 macOS 单机原型，独立 Electron 桌面应用，没有云账户或支付功能；可选开启局域网小屋。

## 发布与更新

推送 `v<package.json 版本>` tag 后，GitHub Actions 在 macOS 构建 Apple 芯片安装包，发布 zip 与 SHA-256 文件；推送 `main` 中的 `site/` 会部署 GitHub Pages。应用在启动后及每 6 小时检查最新公开 Release；用户也可在偏好设置手动检查。升级只在用户点击“下载并安装”后执行：校验 SHA-256、应用标识与版本，预先复制新包，正常退出后替换并重启。失败时恢复旧应用。当前内测包未签名，首次从网页下载的安装步骤可能受 macOS Gatekeeper 限制。

## 启动

需要 Node.js 22.12+。推荐使用已打包的 `release/mac-arm64/Pawprint.app`，双击即可运行，不需要启动网页服务器。启动先显示悬浮宠物（未孵化时为蛋），桌面不显示名字、工具栏或提示条；双击打开小屋，右键进入菜单。

```sh
npm ci
npm run build
npm start
```

开发：`npm run dev`。打包当前 Mac 架构：`npm run package`。

- 基因图鉴：逐项外观预览、初代显现/携带概率、稀有度筛选、搜索、系统伙伴来源，以及多基因组合示例。
- 普通、少见、稀有、珍稀、传说按当前初代显现概率分级，与颜值、能力和市场价值分开。详见 docs/GENES.md。
- 原创参数化 SVG 猫咪，呼吸、眨眼、尾巴和抚摸动画，尊重系统减少动态效果设置。
- 3 位固定基因的系统繁育伙伴，真实继承、外貌概率预览和血统档案。
- 应用内置 Codex 本地日志读取与计价：最近 7 天记录、奖励领取、宠物币账本，无需额外安装统计工具。
- 自动存档、上一份备份、JSON 导出、命名、饲养位扩展。
- 悬浮优先的桌面入口：直接拖动宠物、双击打开小屋、右键菜单、位置记忆、多屏位置恢复、透明留白鼠标穿透。
- macOS 菜单栏爪印图标：打开小屋/钱包、显示隐藏宠物、移回当前屏幕、退出；关闭小屋不会退出应用。
- 右键菜单可打开 Codex / ChatGPT 桌面客户端。通过 macOS bundle ID `com.openai.codex` 唤起，不发送提示词或聊天内容。

## 用量接入与授权

首次连接会展示授权说明。爪印直接读取 `~/.codex/sessions` 与 `~/.codex/archived_sessions` 下的 JSONL 记录。支持 `CODEX_HOME`，也可以在设置中选择自定义 `.codex` 目录。按文件修改时间发现活跃记录，因此旧任务今天继续使用也会计入。

读取器与计价表随应用打包，不调用外部统计程序，不需要另外安装 Node、Python 或 CLI。它在应用自带的 Node worker 中运行，不阻塞主窗口。每 15 分钟自动刷新，也支持手动刷新。只提取身份去重信息、时间、模型、token 计数和服务档位；不保存或上传对话正文，不读取 auth.json、浏览器 Cookie 或 API 密钥。

逐行流式读取，单行最多缓冲 1 MiB，较大的普通消息直接跳过。只缓存统计字段与散列标识。未变化文件复用缓存，变更文件重新流式读取。读取预算 45 秒，worker 总超时 60 秒；未完成扫描不产生新奖励。

支持重复 token_count 去重、归档副本去重、累积计数器重置、模型切换和带边界/出生时间的子任务历史排除。无完整计量字段、未知模型/服务档位或缺少请求明细时，不猜测费用；受影响日期不发新增奖励。它统计本机能观察到的 Codex 记录，不代表跨设备或网页版的全账户用量。

模型价格表版本 `openai-2026-09-20`，包含 GPT-6 Astra、GPT-5.6 系列及若干旧型号。区分普通输入、缓存读取、缓存写入与输出，reasoning 是输出的子集，不重复计费；支持有公开规则的长上下文与 Fast 档位。未标注档位按 Standard 估算。新模型或价格变动需更新应用内置价格表。

参考：[官方价格表](https://developers.openai.com/api/docs/pricing)、[GPT-6 Astra 计价说明](https://developers.openai.com/api/docs/models/gpt-6-astra)。它是 API 等价费用估算，不是订阅账单或实际付款。

升级至独立读取器、切换目录或计价版本时，先建立当天新来源的计数基准。保留旧余额与已确认待领收益，不把已扫描的历史重新奖励一遍；之后新增使用量继续累计。

## 单机经济 v2

- 内置价格表按各模型价格给出 API 等价费用。这不是订阅账单、实际付款或应用收入。
- 每个本地自然日：前 $5 每 $1 得 20 币，之后每 $1 得 2 币，累计向下取整，每日上限 120。
- 首次接入可兑换当天已观测使用量，以前日期只展示，不补发。跨日未领取奖励不自动补发。
- 每日保存 token / 美元高水位、合格等价费用和已领取币。重复刷新、回退报告、断开重连不重置额度。没有新增 token 的单纯费用重估不发币。
- 如价格表重估与新 token 同时发生，日聚合无法准确区分，仍可能影响奖励估算；这是本地试玩的已知限制。连接不同账户、改时钟或改存档也不能作为联网防伪体系。
- 探索蛋 240 币；系统繁育 180 / 220 币；扩建首次 600 币，每扩一位后下一位增加 300 币，初始 3 位，最多 12 位。费用退出流通；钱包显示累计获得、系统支出与当前持有。
- 孵化当天算第 1 个陪伴活跃日。当天打开应用/小屋、主动抚摸，或观察到有效本机用量时，为在小屋的宠物记 1 日；同日不重复累计，不要求多花 token。满 3 个活跃日成年。
- 繁育冷却 48 小时，滚动连续 7 天内每只最多 2 次。安置、接回和重启不清除冷却或历史。
- 这些是初步平衡参数，尚未验证长期留存或稳定货币循环；才艺课程已实现，但达到等级上限后不再收费；游历尚未实现，不把未来玩法当作已有消耗。
- 单机币、本地基因和宠物不承诺自动进入未来联网市场；联网需要独立权威账本与资产签发。

## 基因模型

每个性状携带两份基因。新蛋使用表现位与携带位：初代分别按权重抽两份，第一份显现；繁育从双方各取一份，再随机决定谁显现。旧宠物继续按原有固定显性规则显示，原基因与外貌不重抽。当前无突变。规则是游戏模型，不模拟真实猫的生物学。

基因在领取 / 配种交易中一次生成，孵化只揭晓，不能通过重复点击重新抽取。系统伙伴基因固定，概率预览直接计算同一继承规则。斑点当前使用预设分布，不包含连续斑点位置基因或多物种。稀有度是当前初代池的数学分级，尚未进行长期经济与收藏平衡。

v0.3 升级保留所有旧等位基因 ID。新增类别为旧宠物、未孵化蛋及父母快照补齐中性默认基因；不重新抽取。

## 存储与安全边界

正式存档：`~/Library/Application Support/Pawprint/save-v1.json`。写入临时文件并原子替换，`.bak` 保留前一版本。损坏存档启动时明确报错，不静默覆盖。当前提供导出，不提供 UI 导入 / 恢复；恢复需退出应用后由开发者确认备份文件。

渲染进程启用 sandbox/contextIsolation、禁用 Node，IPC 仅允许固定动作；费用、随机数和写盘位于主进程。主进程串行处理变更，单实例防止并发写盘。不试图把可修改的单机存档包装成可信联网资产。

## 桌面入口与后花园

第一次升级到 v0.2 会启用悬浮入口，保留全部宠物、蛋、余额和基因数据。之后手动隐藏会被记住，可随时从菜单栏恢复。即使没有任何窗口打开，菜单栏仍会驻留；选择「退出爪印」或按 Command+Q 才退出。点击 Dock 图标也可主动打开小屋。

直接拖动宠物移动。双击打开小屋，右键打开原生菜单。名字、工具栏和提示条已移除。外接屏幕拔出后自动将宠物限制到可见工作区，菜单里也提供「把宠物移回当前屏幕」。右键和 macOS 菜单栏提供小屋、基因图鉴、AI 客户端、用量钱包等入口。v0.7 增加可选的 Codex 本机会话反馈，仍不含对话输入或 AI 语音。

## v0.5 后花园

从宠物图鉴点击「去后花园生活」，确认后安置。免费、不返币；宠物仍在同一存档中，名字、基因、血统、成长与繁育历史都保留。后花园不占小屋容量，不继续积累陪伴日，也不能繁育或作为桌面陪伴。小屋有空位（蛋也占位）即可免费接回。

最后一只伙伴休养且没有蛋时，悬浮窗口自动收起，显示偏好保留；接回会恢复。可从侧栏或 macOS 菜单栏进入后花园。

旧存档迁移不改余额、账本、基因或旧蛋。旧宠物的陪伴日由出生当天与已确认用量日补齐，不凭时间经过虚构活跃天数；旧繁育历史从已存后代及最后繁育时间恢复。经济 v2 只影响之后的操作价格。

随机才艺与局域网串门/繁育已在 v0.6 实现；基础会话气泡已在 v0.7 实现，见 docs/NEXT-GAMEPLAY-PROPOSAL.md。

## v0.6 才艺与同事小屋

- 8 项出生才艺：挥爪、伸懒腰、打滚、扭扭舞、转圈、敬礼、月球步、翻跟头。初代按 25/25/20/12/8/5/3/2 权重抽取，配种 70% 从父母中选择、30% 从全局池抽取。才艺在蛋生成时固定。
- 旧宠物与旧蛋一次性补领由稳定 ID 决定的才艺，不重抽外貌，也不扣钱。
- 表演免费。课程 120 币升至熟练，再花 240 币升至拿手；不更换出生才艺、不改变基因、不产币。
- 局域网默认关闭。双方开启后交换连接码，接收方确认配对；串门邀请再次确认后出现访客悬浮窗口，最多两位，最长 10 分钟，可随时送回。访客是分身，不转移宠物所有权。
- 局域网配种由申请方支付 240 币，对方获得 60 币，180 币退出流通，蛋归申请方；双方亲本都计入冷却和次数。确认页面展示基因与才艺条件概率。
- 等待时预留申请方费用、亲本及一个蛋位；未经对方明确取消确认，不擅自返还预留。对方已接受时，取消请求会先取得既有回执并完成结算。断线或重启后自动重试同一请求，不能重复领取。
- 实际网络传输使用带设备证书固定校验的 HTTPS；连接码中的设备证书须与对端一致，配对还会核验请求方拥有所声明的设备证书。每次访问和配种需明确确认。
- 只分享经过白名单筛选的宠物数据、才艺和繁育状态。不分享聊天、用量、目录、余额或完整存档。

这是同事之间的合作模式，本地存档仍可由持有者修改，不是防作弊的交易资产或真钱系统。若对端身份/存档丢失，未决配种需恢复备份后才能自动核对；不提供不经核对的强制退款。详情见 docs/LAN.md。

## v0.7 Codex 会话联动

在「偏好设置 → 桌面陪伴」开启「Codex 会话联动」。默认关闭，与用量连接分开控制。启用后从下一轮开始，只跟随本机 Codex；不支持 ChatGPT 桌面端或网页端。

开工后宠物轻轻摆动，收到明确的 `task_complete` 后表演出生才艺并显示「本轮回复结束啦」，气泡 8 秒后消失。完成仅代表一轮回复结束，不代表任务成功。等待输入和失败识别暂未接入；中断记录若包含匹配的 `turn_id`，只显示停止提示。120 秒没有有效记录时状态变为未知，停止工作动作，绝不猜测完成。多会话分别跟踪，同轮重复结束不重复播放；重启和切换设置不补播历史。

「显示大致主题」另行开启。在内存中用关键词对新用户消息分类，仅显示写代码、排查问题、做设计、分析资料、整理文字、查资料这六种固定标签；不显示或保存原文，不额外调用模型。联动数据不进入游戏存档、导出文件或局域网宠物资料。

事件适配读取 Codex 本地 JSONL，属于兼容性实现，不是官方稳定订阅接口。对当前机器实际观察到的 `task_started`、`task_complete` 和 `item_completed / UserMessage` 结构提供支持，也兼容旧 `user_message`。约每 2 秒读取近期文件新增内容，每 15 秒重新发现旧日期中被继续使用的会话。读取有大小、数量上限；缺失、积压、格式变更会漏掉反馈，不把这些情况当作完成。

官方 App Server 的事件定义参考：https://developers.openai.com/codex/app-server/ 。本应用没有启动新 App Server 或修改 Codex 配置；另起一个服务器不等于能订阅现有桌面任务。

## v0.8 待机散步与玩球

偏好设置 → 桌面陪伴新增「待机散步与玩耍」，默认关闭，可选沿当前位置左右走、沿屏幕边缘巡游。这里的当前位置指桌面宠物所在的高度，不是编辑器的文本行或其他窗口边缘。沿边模式先走向最近边缘，再顺时针爬行；在短暂走动、休息、伸懒腰和可选玩球之间切换。只在当前显示器的可用区域活动，不主动跨屏。

开启约 8 秒后开始第一次动作；之后每段走动约 18–28 秒，休息约 15–35 秒。鼠标距离窗口 28 像素内、拖动、宠物右键菜单、Codex 会话工作中或本人表演才艺时暂停。松开拖动后至少休息 8 秒，采用新位置和新屏幕作为起点。睡眠唤醒不补算路径，屏幕拔出后限制回可见区域。系统「减少动态效果」会暂停巡游和玩球。

玩具球为随宠物显示的 8 秒拨球动画，可以在偏好设置或宠物右键菜单主动拿出；不花币、不额外调用 AI。未打开散步也能单独玩球。停止巡游可使用原来的右键菜单或 macOS 菜单栏「待机散步」开关。自动移动每秒最多约 30 次窗口位置更新，静止时降低频率；仅动作切换时发送界面状态，不逐帧保存存档。

这版是程序驱动的 SVG 动作与路径，不读取其他应用窗口、文字行、屏幕图像或键盘输入。访客暂不自行巡游。

## v0.9 技能与尺寸

技能目录共 17 项：原有 8 项出生才艺 + 100% 赠送的玩球 + 4 项待机技能 + 4 项社交技能。每只宠物保留原来的出生才艺，另拥有一项待机技能和一项社交技能。领取/繁育生成蛋时锁定，不在孵化、升级、重启时重抽。旧宠物与旧蛋按固定 ID 补发两个新槽位，不改原才艺等级、基因、币、血统或冷却。

待机池：认真洗脸 45%、追自己的尾巴 35%、纸箱躲猫猫 17%、星光打盹 3%。社交池：碰爪问好 55%、滚球接力 30%、双猫合拍 12%、星光合奏 3%。初代单项概率 ≥20% 标为基础，≥5% 标为少见，低于 5% 为稀有；赠送技能单独标记。各技能池分别归一化，不跨池相加。繁育每个槽位独立 70% 从父母同类技能中等概率选取、30% 按全局权重抽取；技能页及繁育预览展示对应概率。

待机时会展示这只宠物实际拥有的待机技能。主动表演免费，原来的付费课程仍只训练出生才艺，不出售洗技能或技能抽奖。社交技能需要一位已获准串门的访客；任一参与者能用自己拥有的技能带领另一位，同台表演 8 秒，不把技能永久传授给对方、不改变资产。合演显示在接待方桌面，暂不把动画同步到发起串门者的桌面。退出、断线、访客离开会结束合演；Codex 工作中的反馈优先。

本版本局域网协议带 skills1 标记，新配对和繁育需双方升级到同版。已有未决交易继续尝试读取旧回执/确认取消，不因版本不一致直接退款；旧回执缺失新技能时按固定 ID 补齐。

偏好设置 → 桌面陪伴 → 桌面宠物尺寸，范围 50%–100%，有 60%/75%/100% 快捷按钮。滑块即时缩放桌面宠物、蛋、访客及它们的实际窗口，自动保存；小屋界面大小不变。移动边界按缩小后的窗口计算。

## v0.10 技能标记与菜单栏额度

技能页移除单独的赠送技能区和重复的已拥有列表。玩球并入待机技能池，标为默认掌握；三个池直接标记当前选中伙伴的「已拥有」，保留原概率和演示入口，不改变技能归属或遗传规则。

偏好设置 → 菜单栏额度，可选择周剩余 W、5 小时剩余 5h 或两者。数据直接取自本机 Codex JSONL 的 token_count.rate_limits，不读取登录凭据、浏览器 Cookie 或钥匙串，不调用在线额度接口。每 15 秒重新读取近期修改的会话文件尾部，在隔离的后台工作线程中限制扫描时间、文件数与内存。

按 window_minutes 识别时间窗，不把 primary 固定当作 5 小时；只取主 Codex 额度，不混入 Spark 等独立桶。显示值为 max(0, min(100, 100-used_percent))，不由 token 计数或模型价格推算。超过 15 分钟的记录用 ~ 标记；超过重置时间显示 — / 待更新，不推测 100%。未提供的窗口同样显示 —。同时间的冲突快照保留未知状态。

这是本机最近活动的额度快照，不能识别当前账号，也无法实时反映其他设备的后续使用；切换账号后要等待新记录。记录格式变化或超出读取边界会出现未知/读取错误，菜单可查看记录时间，手动重新读取仍不是在线刷新。额度展示与宠物币计价完全分离，旧余额和奖励规则不变。

## v0.11 固定悬浮画布与中英文

修复缩小宠物后，未缩放的 DOM 布局盒撑大页面、鼠标进入或滚轮操作出现滚动条的问题。悬浮窗口的 html/body/root 固定为原生窗口尺寸，使用布局与绘制隔离及 overflow: clip，宠物和合演画布独立定位。不是只隐藏滚动条；验证包含滚轮和程序滚动均不能移动画布。小屋界面仍正常滚动。

偏好设置 → 界面语言，或原生菜单栏 → 语言，支持简体中文 / English。保存后立即广播到小屋、悬浮宠物、访客和菜单栏，重启保留。覆盖九个页面、基因与技能名称、英文基因搜索、弹窗、错误、原生菜单、通知和会话气泡，英文日期使用 en-US 显示。系统权限面板跟随 macOS 自身的语言，应用包提供英文及简体中文网络权限说明。

语言只作用于展示层和新宠物的默认名字；旧宠物及小屋昵称保持原文，基因、技能、币、账本和网络协议不改变。切换到英文后孵化的新伙伴使用英文默认名，之后切换语言也不会改名。无需联网翻译或额外模型调用。

翻译目录为 core/i18n-en.mjs 与 core/i18n.mjs；React 展示文本通过本地 JSX 适配层转换，不翻译表单值、ID 或游戏对象。用户文本使用 translate=no / RawText，混合用户参数用 formatText 保留原文。新增界面文案应补充目录，并通过英文逐页检查；不要用 DOM 文本替换或翻译存档。

## v0.12 分层跑跳与菜单栏恢复

新增侧身四足角色骨架，头部、身体、远近四肢与下肢、尾巴独立动画。行走与短跑有不同步频，跳跃包含预备下蹲、腾空、收腿、落地缓冲及阴影变化。左右方向、屏幕边缘朝向、移动速度适配宠物尺寸；鼠标靠近、拖动、会话工作或减少动态效果时继续暂停。原有正面形象保留在档案与技能展示中。

偏好设置 → 桌面陪伴 → 预览跑跳，可看约 6.5 秒的跑跳样例，不花币。侧身用现有基因控制毛色、花纹、眼睛、耳朵、鼻口、尾巴和体型。当前为动作与分层基础，尚无装备背包、穿脱或商城；部件分层为后续装备覆盖提供位置，不允许用换装重抽出生基因。

菜单栏图标在其他后台服务之前创建，使用固定 GUID 保留位置，持有原生图像，并在主题变化时重绘、唤醒时重建。已销毁的入口会自动恢复。偏好设置 → 菜单栏额度增加恢复按钮、入口状态及仅图标模式。系统级关闭、空间不足或刘海遮挡不等于对象被销毁，应用不会自动改写系统显示权限。

本次实际排查中，进程、宠物和额度更新均正常，macOS 的允许 Pawprint 显示开关原为开启；将它关闭再开启后，用户确认图标恢复。未确认导致显示状态变化的具体触发条件，不把这一现象误报为应用崩溃。

## v0.13 统一正面 2D

用户选定 A 风格。浮窗待机、走跑和小跳共用原有 Cat 模型，不再切换另一套侧身形象，不再沿屏幕边缘倒挂/旋转。头、尾、两只前爪使用独立外层关节；连续动画时钟和平滑起停避免模型切换。基因缩放、花纹和原有技能保留。

旧 edges 设置兼容为沿当前位置水平散步。偏好设置 → 桌面陪伴 → 预览跑跳，可以演示完整动作。当前是正面动作版本，尚未实现概念图的四足 3/4 视角或装备系统。进度见 docs/PROGRESS-2D.md。

## v0.14 四足步态

在统一 Cat 内增加后腿、躯干及颈部动作，左右小跑时形成浅斜向姿态，停下回到坐姿。跳跃中途被鼠标打断时平滑落地。面部/花纹不切换、不镜像，基因和存档保持不变。6 条桌面回归通过，安装后的真实宠物已预览检查。仍是正面脸为主的 2D 动作，未新增装备系统。
